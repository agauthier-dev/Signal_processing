# Signal Processing

Python scripts for simple signal processing functions,
written during Signal Processing classes.

## Contents

- Fourier series — coefficient calculation and visualisation
- Fourier transform — coefficient calculation and visualisation
- Signal reconstruction from Fourier coefficients
- Convolution — calculation and visualisation
- Correlation — calculation and visualisation

## Requirements

- Python 3.x
- NumPy
- Matplotlib

## Usage

Each script can be run independently with IDLE or any Python interpreter.
